# 第4章：複数のデータを一気に扱う！〜スライスとマップ〜

変数が「1つのデータを入れる箱」だとしたら、今回は「たくさんのデータを入れる棚」や「見出し付きの引き出し」の作り方を学びます。この章を理解すれば、リスト一覧の表示や、データ検索機能の基礎が作れるようになります！

コードを書くときは、引き続きターミナルから `vim main.go` を使ってサクサク編集していきましょう。

---

### 4.1 配列とスライスの違い（Go言語の超重要ポイント）

Go言語で複数のデータを一列に並べて管理する方法には、「配列」と「スライス」の2種類があります。

* **配列 (Array):** 最初に「この箱は3個用です」とサイズを決めたら、後からサイズを変更できない固定長のリスト。
* **スライス (Slice):** データが増えたら自動的にサイズが拡張される、伸縮自在のリスト。

ハッカソンでは、APIから取得したデータやユーザーが入力したデータを順次追加していくことが多いため、**99%の場面で「スライス」を使います。**

---

### 4.2 伸縮自在のリスト「スライス」の使い方

スライスを作る時は、要素の数（サイズ）を指定せずに `[]データ型` と書きます。

~~~go
package main

import "fmt"

func main() {
    // string型のデータを複数持てるスライスを作成
    stores := []string{"コンビニA", "コンビニB", "コンビニC"}

    fmt.Println(stores)

    // 1番目のデータを取り出す（※コンピュータの世界は0から数え始めます！）
    fmt.Println("最初の店舗:", stores[0])
}
~~~

**データの追加（`append`）**
スライスに新しいデータを追加したい時は、`append`（アペンド）という便利な組み込み関数を使います。

~~~go
package main

import "fmt"

func main() {
    stores := []string{"コンビニA"}
    
    // "コンビニB" を追加して、元の stores に上書きする
    stores = append(stores, "コンビニB")
    stores = append(stores, "コンビニC", "コンビニD") // 複数同時に追加も可能！

    fmt.Println(stores) // [コンビニA コンビニB コンビニC コンビニD] と表示される
}
~~~

### 4.3 見出し付きの引き出し「マップ」

スライスが「番号（0, 1, 2...）」でデータを管理するのに対し、「マップ (Map)」は「好きな名前（キー）」でデータを管理します。他の言語では「辞書（Dictionary）」や「連想配列」と呼ばれることもあります。

例えば、店舗名（文字列）をキーにして、トイレの貸し出し状況（真偽値 `bool`）を値として保存したい場合に大活躍します。

~~~go
package main

import "fmt"

func main() {
    // map[キーの型]値の型 の形式で作成します
    toiletStatus := map[string]bool{
        "コンビニA": true,   // 貸し出しOK
        "コンビニB": false,  // 貸し出し不可
    }

    // データの取り出し
    fmt.Println("コンビニAの状況:", toiletStatus["コンビニA"])

    // データの追加と更新
    toiletStatus["コンビニC"] = true // 新しく追加
    toiletStatus["コンビニB"] = true // 既存のデータを上書き（false -> true）

    fmt.Println("全体の状況:", toiletStatus)
}
~~~
マップは、ハッカソンで外部のAPI（AWSの各種サービスなど）からJSON形式のデータを受け取る際、そのデータをGo言語の中で扱うための基盤にもなる非常に重要な機能です。

### 4.4 `for` 文と組み合わせた最強のループ（`range`）

第3章で学んだ `for` 文は、スライスやマップのデータを1つずつ取り出して処理する時に真価を発揮します。その際に欠かせないのが `range`（レンジ）というキーワードです。

**スライスを `range` で回す例**

~~~go
package main

import "fmt"

func main() {
    stores := []string{"コンビニA", "コンビニB", "コンビニC"}

    // rangeを使うと、「インデックス番号」と「その中身」が順番に取り出せる
    for index, name := range stores {
        fmt.Println(index, "番目の店舗は", name, "です")
    }
}
~~~

もしインデックス番号が不要な場合は、Go言語特有のルールである「使わない変数はエラーになる」を回避するため、アンダースコア `_` （ブランク識別子）を使って「受け取るけど捨てる」と明示します。

~~~go
    for _, name := range stores {
        fmt.Println("店舗名:", name)
    }
~~~

### 4.5 第4章の確認問題

**問題1**
サイズがあらかじめ決まっておらず、後から自由にデータを追加できるGo言語のリスト（配列のようなもの）を何と呼びますか？

**問題2**
スライス `list` に、新しい文字列データ `"新しいデータ"` を追加するためのコードを書いてください。

**問題3**
キーに文字列（`string`）、値に整数（`int`）を持つマップを作成する時の型の書き方は `map[キーの型]値の型` に従うとどうなりますか？

---

### 4.6 解答と解説

**【第4章の解答】**

* **問題1:** スライス (Slice)
    * *解説:* ハッカソンで「配列」と言えば、基本的にはこの「スライス」を指して会話が進むことが多いです。固定長の真の配列（`[3]int` のようにサイズを指定するもの）は、パフォーマンスを極限までチューニングする特殊な場面以外ではあまり使いません。
* **問題2:** `list = append(list, "新しいデータ")`
    * *解説:* `append(スライス, 追加するデータ)` と書きますが、追加した結果を再び元の変数 `list` に代入（上書き）するのを忘れないようにするのがポイントです。
* **問題3:** `map[string]int`
    * *解説:* 例えば、ユーザー名をキーにして、その人のスコアや年齢（整数）を保存したい時などに `map[string]int` を使います。
