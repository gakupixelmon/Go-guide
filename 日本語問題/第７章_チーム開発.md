## 第7章：チーム開発の必須スキル！〜ファイルの分割とパッケージ（package）〜

これまでの章では、ファイルの先頭に常に `package main` と書いてきました。これは「このファイルはプログラムの実行開始地点（メイン）ですよ」という宣言でした。

今回は、メイン以外の「部品」となるパッケージを自作し、複数のファイルをつなぎ合わせて一つのアプリを動かす方法を学びます。

---

### 7.1 プロジェクトの準備（Go Modules）

複数のファイルや外部の便利なツールを扱う場合、まずはGo言語に「ここが私たちのプロジェクト（アプリ）の拠点です」と教えてあげる必要があります。この仕組みを **Go Modules** と呼びます。

ターミナルを開き、新しく作業用のフォルダ（例: `myapp`）を作り、その中に移動して以下のコマンドを実行します。

~~~bash
mkdir myapp
cd myapp
go mod init myapp
~~~

すると、フォルダ内に `go.mod` というファイルが自動作成されます。これがプロジェクトの設計図のような役割を果たし、パッケージの管理を行ってくれます。

---

### 7.2 部品となる新しいパッケージを作る

今回は、「地図や店舗の情報を扱う機能」を別のフォルダに分けてみましょう。
ターミナルで `myapp` フォルダの中に新しく `mapinfo` というフォルダを作ります。

~~~bash
mkdir mapinfo
cd mapinfo
nvim toilet.go
~~~

Neovimが開いたら、以下のコードを記述します。ここで重要なのは、先頭を `package main` ではなく、**フォルダ名と同じ `package mapinfo` にする**ことです。

~~~go
// myapp/mapinfo/toilet.go
package mapinfo

// 店舗の構造体を定義
type Store struct {
    Name      string
    HasToilet bool
}

// トイレが使えるかどうかを判定する関数
// ★注目：関数名の最初が大文字になっています！
func CheckStatus(s Store) string {
    if s.HasToilet {
        return s.Name + "はトイレ利用可能です！"
    }
    return s.Name + "はトイレがありません。"
}
~~~
保存して終了（`:wq`）します。

---

### 7.3 Go言語最大のルール：大文字と小文字の魔法

ここで、Go言語における**超重要ルール**をお伝えします。

Go言語では、別のパッケージ（ファイル）から構造体や関数を呼び出して使いたい場合、**名前の最初を必ず「大文字」にしなければなりません**。これを「エクスポート（公開）される」と言います。

* **大文字で始まる（例: `CheckStatus`, `Store`, `Name`）**: 他のパッケージからも自由に使える（公開）。
* **小文字で始まる（例: `checkStatus`, `store`, `name`）**: そのパッケージの中（同じフォルダ内）でしか使えない（非公開）。

他の言語によくある `public` や `private` といったキーワードを使わず、大文字・小文字だけで公開範囲が決まるのがGo言語のシンプルで美しい特徴です。

---

### 7.4 分割したファイルを `main.go` でつなぎ合わせる

それでは、ターミナルで一つ上のフォルダ（`myapp`）に戻り、`main.go` を作成して、先ほど作った部品を呼び出してみましょう。

~~~bash
cd ..
nvim main.go
~~~

~~~go
// myapp/main.go
package main

import (
    "fmt"
    "myapp/mapinfo" // 自作したパッケージをインポート！
)

func main() {
    // mapinfoパッケージのStore構造体を使う
    // パッケージ名.構造体名 という形で呼び出します
    myStore := mapinfo.Store{
        Name:      "ハッカソンマート 渋谷店",
        HasToilet: true,
    }

    // mapinfoパッケージのCheckStatus関数を使う
    result := mapinfo.CheckStatus(myStore)
    
    fmt.Println(result)
}
~~~

保存して終了（`:wq`）したら、`myapp` フォルダでアプリを実行します！

~~~bash
go run main.go
~~~
`ハッカソンマート 渋谷店はトイレ利用可能です！` と表示されれば大成功です！
これであなたは、複数のファイルやフォルダにまたがる本格的なプログラムを構築できる能力を手に入れました。

### 7.5 第7章の確認問題

**問題1**
複数のファイルや外部パッケージを管理するために、プロジェクトの最初に実行するコマンド `go mod _______ プロジェクト名` の空欄に入る英単語は何ですか？

**問題2**
自分が作ったパッケージの関数を、別のパッケージ（`main`など）から呼び出せるように公開するには、関数名をどのように命名する必要がありますか？

**問題3**
`user` パッケージの中に、他のファイルからは隠しておきたい（非公開にしたい）パスワード計算の関数を作りたいです。関数名として適切なのは `CalculatePassword` と `calculatePassword` のどちらでしょうか？

---

### 7.6 解答と解説

**【第7章の解答】**

* **問題1:** `init`
    * *解説:* `go mod init` は、新しくアプリ開発を始める際の「儀式」のようなものです。これを行うことで、どこからでも自分の作ったパッケージを読み込めるようになります。
* **問題2:** 名前の最初の1文字を大文字にする。
    * *解説:* 構造体のフィールド名（中身の変数名）も同様です。例えば `Store` 構造体の `Name` を小文字の `name` にしてしまうと、`main.go` から `myStore.name` とアクセスした時にエラーになってしまいます。
* **問題3:** `calculatePassword`
    * *解説:* 小文字で始めることで、そのパッケージ内でしか使えない安全な（カプセル化された）関数を作ることができます。ハッカソンでも、見せたくない複雑な裏側の処理は小文字にして隠すのがベストプラクティスです。
