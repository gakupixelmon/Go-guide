# ハッカソン特化型 Go言語ブートキャンプ

## 第3章：プログラムの道案内！〜条件分岐と繰り返し（if / for）〜

プログラムは基本的に上から下へと順番に実行されますが、状況に応じて別の処理を行ったり（条件分岐）、同じ処理を何度も行ったり（繰り返し）することで、一気に実用的なアプリに近づきます。

ターミナル上でファイルの作成や編集を行う際は、`vim main.go` のようにVimを用いてサクサクとコードを書いていきましょう！

---

### 3.1 「もし〜なら」を実現する `if` 文

特定の条件を満たした時だけ処理を行いたい場合は、`if` 文を使います。

~~~go
package main

import "fmt"

func main() {
    score := 85

    // 条件式が true（真）の時だけ、中括弧 {} の中が実行される
    if score >= 80 {
        fmt.Println("素晴らしい！高得点です！")
    }
}
~~~

**よく使う条件の書き方（比較演算子）**
* `a == b` （aとbは等しい） ※ `=` が2つであることに注意！
* `a != b` （aとbは等しくない）
* `a > b` （aはbより大きい）
* `a >= b` （aはb以上）

### 3.2 複数の条件を組み合わせる `else if` と `else`

「もし〜ならA、そうではなく〜ならB、どちらでもなければC」というように、複数のルートを作りたい場合は `else if` と `else` を繋げます。ハッカソンでは「入力エラーの時はエラーメッセージを返し、正常な時はデータを保存する」といったAPIの処理で頻繁に使います。

~~~go
package main

import "fmt"

func main() {
    passwordLength := 5

    if passwordLength >= 8 {
        fmt.Println("安全なパスワードです。")
    } else if passwordLength >= 5 {
        fmt.Println("パスワードが少し短いです。8文字以上を推奨します。")
    } else {
        fmt.Println("エラー：パスワードが短すぎます！")
    }
}
~~~

### 3.3 繰り返し処理の王様 `for` 文

Go言語には、繰り返し処理を行うための構文が **`for` のみ**しかありません。（他の言語にある `while` などは存在しません）。その分、覚えることが少なくてシンプルです。

**基本の形：回数を指定して繰り返す**
「0から始めて、5未満の間、1ずつ増やしながら繰り返す」という最もスタンダードな書き方です。

~~~go
package main

import "fmt"

func main() {
    // i := 0 (初期値) ; i < 5 (続ける条件) ; i++ (1回終わるごとの処理)
    for i := 0; i < 5; i++ {
        fmt.Println(i, "回目のループです")
    }
}
~~~
※ `i++` は「変数 `i` の中身を1増やす」という便利な書き方です。

**条件だけを指定して繰り返す（他の言語のwhileのような書き方）**
初期値や1回ごとの処理を省略し、条件式だけを書くこともできます。

~~~go
package main

import "fmt"

func main() {
    count := 3

    // countが0より大きい間、ずっと繰り返す
    for count > 0 {
        fmt.Println("カウントダウン:", count)
        count-- // countを1減らす
    }
    fmt.Println("スタート！")
}
~~~

### 3.4 無限ループと抜け出し方（`break`）

ハッカソンで「サーバーを立ち上げて、ずっとユーザーからのアクセスを待ち続ける」といったプログラムを書くときは、わざと**無限ループ**を作ります。Go言語では、条件を何も書かないだけで無限ループになります。

途中で強制的にループから抜け出すには `break` を使います。

~~~go
package main

import "fmt"

func main() {
    hp := 10

    for { // 条件を書かないと無限ループになる
        fmt.Println("モンスターの攻撃！")
        hp -= 3 // hpを3減らす（hp = hp - 3 と同じ）
        
        if hp <= 0 {
            fmt.Println("HPが0になった。ループを終了します。")
            break // ここでforループから強制的に脱出！
        }
    }
}
~~~

### 3.5 第3章の確認問題

**問題1**
変数 `age` が20以上であれば「大人です」と表示し、そうでなければ（20未満であれば）「未成年です」と表示する `if` 〜 `else` 文のコードを書いてみてください。（頭の中で組み立てるか、手元で書いてみてください）

**問題2**
Go言語において、1回の繰り返しが終わるごとに変数 `x` の値を1増やすための短い書き方は何でしょうか？

**問題3**
`for` 文の中で特定の条件を満たした時に、ループを強制的に終了させて外に抜け出すためのキーワード（命令）は何ですか？

---

### 3.6 解答と解説

**【第3章の解答】**

* **問題1:**
~~~go
if age >= 20 {
    fmt.Println("大人です")
} else {
    fmt.Println("未成年です")
}
~~~
*解説:* `>=` は「〜以上」を表します。`if` と `else` を組み合わせることで、YESかNOかの2パターンの処理をきれいに分けることができます。

* **問題2:** `x++`
*解説:* `x = x + 1` と書くこともできますが、プログラミングでは頻繁に1を増やす処理を行うため、`++`（インクリメント）という便利な書き方が用意されています。逆に1減らす時は `x--`（デクリメント）を使います。

* **問題3:** `break`
*解説:* 無限ループ（`for {}`）と `if` 文、そしてこの `break` を組み合わせることで、「ある特定のデータが見つかるまで探し続ける」といった柔軟なプログラムを作ることができます。
