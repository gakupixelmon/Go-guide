## 第2章：データを操る！〜変数と基本のデータ型〜

プログラムの主役は「データ」です。ハッカソンでWebサービスやAPIを作る際も、ユーザーの名前を受け取ったり、計算結果を一時的に保存したりするための「箱」が必要になります。この章では、その箱である「変数」の使い方を学びましょう。

---

### 2.1 変数（箱）の作り方

Go言語で変数を作る（宣言する）には、大きく分けて2つの方法があります。

**① 丁寧な書き方（`var` キーワード）**
「この箱にはこういう種類のデータが入りますよ」と明示的に宣言する方法です。

~~~go
package main

import "fmt"

func main() {
    var message string = "こんにちは！"
    fmt.Println(message)
}
~~~
* `var`：変数を宣言する合図です。
* `message`：変数の名前（わかりやすい名前を自由に決められます）。
* `string`：データ型の種類（この場合は文字列）。

**② ハッカソンで大活躍！省略記法（`:=`）**
Go言語には、入ってきたデータから型を自動的に推論して、変数の宣言と代入を同時に行ってくれる便利な書き方があります。ハッカソンのようなスピード勝負の場では、この書き方が圧倒的に多く使われます。

~~~go
package main

import "fmt"

func main() {
    // varとstringを省略して、一気に箱の作成と中身の代入を行う
    message := "ハッカソンへようこそ！"
    fmt.Println(message)
}
~~~
※注意点：初めて変数を作ってデータを入れる時だけ `:=` を使い、後から中身を入れ替える（再代入する）時は `=` だけを使います。

### 2.2 覚えておくべき基本のデータ型

Go言語は「静的型付け言語」と呼ばれ、1つの箱（変数）に入れられるデータの種類（型）が厳密に決まっています。まずは以下の4つを覚えれば十分です。

1. **`string`（文字列）**: 文字の集まり。必ずダブルクォーテーション `"` で囲みます。（例: `"Go言語"`, `"123"`）
2. **`int`（整数）**: 整数の数値。（例: `10`, `-5`）
3. **`float64`（浮動小数点数）**: 小数点を含む数値。（例: `3.14`）
4. **`bool`（真偽値）**: 正しいか、間違っているかの2択を表す値。条件分岐などで大活躍します。（値は `true` か `false` のみ）

~~~go
package main

import "fmt"

func main() {
    name := "Team A"      // 自動的にstring型になる
    score := 100          // 自動的にint型になる
    isWinner := true      // 自動的にbool型になる

    fmt.Println(name, score, isWinner)
}
~~~

### 2.3 データの計算と結合

数値同士は四則演算ができ、文字列同士は `+` を使ってくっつけることができます。

~~~go
package main

import "fmt"

func main() {
    // 数値の計算
    a := 10
    b := 3
    fmt.Println(a + b)  // 足し算: 13
    fmt.Println(a - b)  // 引き算: 7
    fmt.Println(a * b)  // 掛け算: 30
    fmt.Println(a / b)  // 割り算: 3（※整数(int)同士の割り算は小数点以下が切り捨てられます）

    // 文字列の結合
    greeting := "Hello, "
    user := "Goエンジニア"
    fmt.Println(greeting + user) // 「Hello, Goエンジニア」になる
}
~~~

### 2.4 第2章の確認問題

**問題1**
省略記法（`:=`）を使って、`age` という名前の変数に整数 `20` を代入するコードを1行で書いてください。

**問題2**
Go言語において、正しいか間違っているか（`true` または `false`）の2つの値しか持たないデータ型を何と呼びますか？

**問題3**
`x := "10"` と `y := "20"` があります。 `fmt.Println(x + y)` を実行すると、画面には何が表示されるでしょうか？

---

### 2.5 解答と解説

**【第1章の解答】**
* **問題1:** `fmt` （文字を出力したり、フォーマットを整える際に使う標準パッケージです）
* **問題2:** `main` 関数 （`func main()` はプログラムの実行スタート地点になります）
* **問題3:** `go run main.go` （コンパイルと実行を裏側で同時に行ってくれる便利なコマンドです）

**【第2章の解答】**
* **問題1:** `age := 20`
* **問題2:** `bool` 型（ブール型）
* **問題3:** `1020`
    * **解説:** `"10"` と `"20"` はダブルクォーテーションで囲まれているため、数値ではなく「文字列（`string`）」として扱われます。文字列同士の `+` は「文字をそのままくっつける」という処理になるため、数学的な計算の `30` にはならず `1020` となります。ハッカソンでも「数値のつもりで足したら文字列になっていてエラーが起きた！」というのは非常によくあるミスなので注意しましょう。
