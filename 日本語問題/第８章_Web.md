## 第8章：世界とつながる！〜Webサーバーの構築〜

これまではターミナル（黒い画面）の中だけで結果を表示していましたが、実際のWebサービスはGoogle ChromeやSafariなどの「ブラウザ」を通してユーザーに届けられます。

Go言語には、強力なWebサーバーを構築するための機能が最初から標準で備わっています。外部の複雑なソフトウェアを用意しなくても、わずか数行のコードでサーバーを起動させることができます。

---

### 8.1 最小構成のWebサーバーを立ち上げる

まずは実際に動かしてみましょう。ターミナルで `nvim main.go` と入力し、Neovimで以下のコードを記述します。

~~~go
package main

import (
    "fmt"
    "net/http" // Webサーバーを構築するための標準パッケージ
)

// ユーザーからアクセスがあった際に実行される処理（ハンドラ関数）
func handler(w http.ResponseWriter, r *http.Request) {
    // ターミナルではなく、接続してきたブラウザ(w)に向けて文字を書き込む
    fmt.Fprint(w, "Hello, Hackathon Web!")
}

func main() {
    // 「/」 (ルート: 一番トップのURL) にアクセスが来たら、handler関数を実行するように紐付ける
    http.HandleFunc("/", handler)

    fmt.Println("サーバーを起動しました。http://localhost:8080 にアクセスしてください。")
    
    // ポート8080番でサーバーを起動し、リクエストの待機状態に入る
    http.ListenAndServe(":8080", nil)
}
~~~

コードを書き終えたら `Esc` を押し、`:wq` で保存してNeovimを終了します。

---

### 8.2 プログラムの実行とブラウザからの確認

**1. サーバーの起動**
ターミナルで以下のコマンドを実行します。

~~~bash
go run main.go
~~~
`サーバーを起動しました。http://localhost:8080 にアクセスしてください。` と表示されたまま、ターミナルの入力待ち状態が戻ってこなくなります。これはエラーではなく、**「サーバーが常に起動して、外部からのアクセスを監視（待機）している状態」**です。

**2. ブラウザからアクセスする**
普段お使いのWebブラウザ（Chromeなど）を開き、URLを入力する欄に以下を入力してEnterを押してください。

`http://localhost:8080`

画面に `Hello, Hackathon Web!` と表示されれば成功です！あなたのパソコンが立派なWebサーバーとして機能しています。

**3. サーバーの停止**
サーバーを停止してターミナルの操作に戻りたい場合は、ターミナル上で `Ctrl` キーを押しながら `c` キーを押します（Ctrl+C）。これは実行中のプログラムを強制終了させるターミナルの標準コマンドです。

### 8.3 コードと関数の丁寧な解説

今回インポートした `net/http` パッケージの重要な要素を紐解いていきましょう。

* **`http.HandleFunc("/", handler)`**
  これは「ルーティング（経路案内）」を設定する関数です。第一引数の `"/"` はURLのパス（道筋）を表し、第二引数の `handler` は「そのパスにアクセスが来た時に実行する関数」を指定しています。

* **`func handler(w http.ResponseWriter, r *http.Request)`**
  Webサーバーの処理を行う関数（ハンドラ）は、必ずこの2つの引数を受け取るルールになっています。
  * `w http.ResponseWriter`: サーバーからブラウザ（クライアント）へ、文字やデータを「返信（レスポンス）」するための書き込み用の箱です。
  * `r *http.Request`: ブラウザから送られてきた「要求（リクエスト）」の情報（アクセスしたURLや、送信されたデータなど）が詰まっている箱です。

* **`fmt.Fprint(w, "文字列")`**
  今までの `fmt.Println` はターミナルに出力していましたが、`fmt.Fprint` は第一引数に指定した宛先（今回は `w` = ブラウザへの返信箱）に対して文字列を書き込むための関数です。

* **`http.ListenAndServe(":8080", nil)`**
  サーバーを起動する命令です。`:8080` は「ポート番号」と呼ばれる通信の窓口の番号です。Web開発では開発用に `8080` や `3000` といった番号がよく使われます。

### 8.4 第8章の確認問題

少し語彙のレベルを上げ、実践的な用語を用いた問題に挑戦してみましょう。

**問題1**
Go言語で標準的にWebサーバーを構築（こうちく）するためにインポートするパッケージ（機能のまとまり）は次のうちどれですか？
A) `net/http`
B) `os/exec`
C) `math/rand`

**問題2**
ユーザーからのリクエストを受け取り、ブラウザに文字などのレスポンスを書き込む（出力する）役割を持つ型はどれですか？
A) `http.Request`
B) `http.ResponseWriter`
C) `http.ServeMux`

**問題3**
サーバーを指定したポート番号（例：8080）で起動し、リクエストの待機（監視）を開始するための関数はどれですか？
A) `http.ListenAndServe`
B) `http.HandleFunc`
C) `http.Redirect`

**問題4**
URLのパス（例：`/` や `/api`）と、それを処理する関数（ハンドラ）を紐付ける（マッピングする）役割を持つ関数はどれですか？
A) `http.Get`
B) `http.Post`
C) `http.HandleFunc`

**問題5**
ブラウザに文字列を出力する際、`fmt.Println` の代わりに、指定した書き込み先（`ResponseWriter`など）へフォーマットして出力する関数はどれですか？
A) `fmt.Fprint`
B) `fmt.Scan`
C) `fmt.Errorf`

---

### 8.5 解答と解説

**問題1の正解：A**
*解説：*
* **A) `net/http`**：ネットワーク通信やHTTPプロトコル（Webの通信ルール）を扱うパッケージです。
* **B) `os/exec`**：OS（オペレーティングシステム）の外部コマンドを実行するためのパッケージです。
* **C) `math/rand`**：乱数（ランダムな数値）を生成（計算）するためのパッケージです。

**問題2の正解：B**
*解説：*
* **A) `http.Request`**：クライアントから送られてきた要求（リクエスト）の情報（URLやデータなど）を格納する型です。
* **B) `http.ResponseWriter`**：サーバーからクライアント（ブラウザ）へ応答（レスポンス）を書き込んで返すための型（インターフェース）です。
* **C) `http.ServeMux`**：送られてきたURLに応じて、どの処理（ハンドラ）に振り分けるかを決定するルーター（マルチプレクサ）の型です。

**問題3の正解：A**
*解説：*
* **A) `http.ListenAndServe`**：指定したポート（通信の窓口）でサーバーを起動（Listen：リッスン）し、リクエストの処理（Serve：サーブ）を開始する関数です。
* **B) `http.HandleFunc`**：特定のURLに対する処理関数を登録（紐付け）する関数です。
* **C) `http.Redirect`**：アクセスしてきたユーザーを別のURLへ転送（リダイレクト）する関数です。

**問題4の正解：C**
*解説：*
* **A) `http.Get`**：指定したURLに対してGETリクエスト（データの取得要求）を送信する関数です。
* **B) `http.Post`**：指定したURLに対してPOSTリクエスト（データの送信要求）を送信する関数です。
* **C) `http.HandleFunc`**：特定のパス（URLの末尾）にアクセスがあった際に、どの関数（ハンドラ）を実行するかを紐付ける関数です。

**問題5の正解：A**
*解説：*
* **A) `fmt.Fprint`**：ファイルやネットワーク通信（今回のResponseWriterなど）の指定した出力先（io.Writer）に対して、文字列を書き込む（出力する）関数です。
* **B) `fmt.Scan`**：標準入力（ターミナルでのキーボード入力など）からデータを読み取る関数です。
* **C) `fmt.Errorf`**：指定したフォーマットに従って、新しいエラー（異常状態のデータ）を作成する関数です。
