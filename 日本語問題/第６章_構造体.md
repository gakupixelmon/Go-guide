## 第6章：オリジナルのデータ型を作る！〜構造体（struct）〜

これまで、`string`（文字列）や `int`（整数）、`bool`（真偽値）といった基本のデータ型を学んできました。しかし、現実世界のデータはもっと複雑です。

例えば、「コンビニ」というデータをプログラムで表したい場合、店舗名（文字列）、トイレの有無（真偽値）、現在地からの距離（整数）など、異なる種類のデータがひとまとめになっている必要があります。これを実現するのが**構造体（struct）**です。

---

### 6.1 構造体（struct）の設計図を作る

構造体は、様々なデータ型を詰め合わせた「オリジナルのデータ型」を作るための設計図です。

まずは、ターミナルで `nvim main.go` と入力し、Neovimを開いて以下のコードを書いてみましょう。

~~~go
package main

import "fmt"

// Store という名前の新しいデータ型（構造体）を定義する
// type [構造体の名前] struct の形式で書きます
type Store struct {
    Name      string // 店舗名
    HasToilet bool   // トイレの有無
    Distance  int    // 距離（メートル）
}

func main() {
    // 構造体の設計図をもとに、実際のデータ（実体）を作る
    myStore := Store{
        Name:      "ハッカソンマート 渋谷店",
        HasToilet: true,
        Distance:  150,
    }

    // fmt.Println で中身を丸ごと確認できます
    fmt.Println(myStore)
}
~~~

**コードとターミナル操作の解説:**
* **`type Store struct { ... }`**: ここで「Store」という新しい型を定義しています。中に入っている変数のことを「フィールド」と呼びます。
* **`Store{ ... }`**: 定義した設計図をもとに、実際のデータを作成しています（これを「インスタンス化」と呼んだりします）。
* **Neovimでの保存と終了**: コードを書き終えたら、`Esc`キーを押してノーマルモードに戻り、`:wq` と入力して `Enter` を押します。これは「write（保存して）quit（終了する）」という、Neovimの非常に重要なコマンドです。
* **実行**: ターミナルに戻ったら、`go run main.go` を実行します。`{ハッカソンマート 渋谷店 true 150}` のように、まとまったデータが表示されれば成功です！

---

### 6.2 構造体の中身を取り出す・書き換える

構造体の中にある特定のデータ（フィールド）だけを使いたい場合は、`.`（ドット）を使ってアクセスします。

先ほどの `main.go` をNeovimで開き、`main` 関数の中を以下のように書き換えてみましょう。

~~~go
package main

import "fmt"

type Store struct {
    Name      string
    HasToilet bool
    Distance  int
}

func main() {
    myStore := Store{
        Name:      "ハッカソンマート 渋谷店",
        HasToilet: false,
        Distance:  150,
    }

    // ドット(.)を使って、特定のフィールドだけを読み取る
    fmt.Println("店舗名:", myStore.Name)

    // ドット(.)を使って、特定のフィールドのデータを書き換える
    if !myStore.HasToilet {
        fmt.Println("トイレがなかったので、改装工事をします...")
        myStore.HasToilet = true // データを true に更新
    }

    fmt.Println("トイレあり？:", myStore.HasToilet)
}
~~~

**コードの解説:**
* **`myStore.Name`**: これで「ハッカソンマート 渋谷店」という文字列だけを取り出すことができます。
* **`!myStore.HasToilet`**: `!` は「否定（Not）」を意味する記号です。`myStore.HasToilet` が `false` の場合、`!false` は `true` となるため、if文の中の処理が実行されます。

### 6.3 構造体とスライスを組み合わせる（超実践編）

ハッカソンでアプリの裏側（APIサーバー）を作る際、データベースから取得した「複数の店舗リスト」を扱うことになります。この時、「構造体のスライス」という強力な組み合わせを使います。

第4章で学んだスライス（データのリスト）の箱に、今回作った構造体を入れてみましょう。

~~~go
package main

import "fmt"

type Store struct {
    Name      string
    HasToilet bool
    Distance  int
}

func main() {
    // Store構造体を複数入れられるスライスを作成
    stores := []Store{
        {Name: "店舗A", HasToilet: true, Distance: 100},
        {Name: "店舗B", HasToilet: false, Distance: 50},
    }

    // appendを使って後から新しい店舗を追加
    stores = append(stores, Store{Name: "店舗C", HasToilet: true, Distance: 200})

    // for文とrangeを使って、条件に合う店舗だけを探す
    fmt.Println("--- トイレが使える店舗一覧 ---")
    for _, s := range stores {
        if s.HasToilet == true { // トイレがある店舗だけを表示
            fmt.Printf("%s (現在地から %dm)\n", s.Name, s.Distance)
        }
    }
}
~~~

**コードの解説:**
* **`[]Store{ ... }`**: `string` や `int` のスライスを作った時と同じように、`Store` 型のスライスを作っています。
* **`fmt.Printf`**: `Println` と似ていますが、「フォーマット（f）」を指定して文字を出力する関数です。`%s` の部分に文字列（Name）が、`%d` の部分に整数（Distance）が入り、`\n` で改行します。見栄えを整えたい時に便利です。

### 6.4 第6章の確認問題

**問題1**
異なるデータ型をひとまとめにして、オリジナルのデータ型を作るためのGo言語の機能を何と呼びますか？（英単語でお答えください）

**問題2**
作成した構造体 `user` の中にある `Age` というフィールド（年齢データ）にアクセスし、その値を `20` に書き換えるためのコードを1行で書いてください。

**問題3**
Neovimでファイルを編集した後、変更を保存して終了するためにターミナル（Neovimのコマンドライン）で入力するコマンドは何ですか？

---

### 6.5 解答と解説

**【第6章の解答】**

* **問題1:** struct（構造体）
    * *解説:* ハッカソンで設計を行う際、「今回はどんなstructを作ろうか？」という会話が頻繁に飛び交います。データの設計図として非常に重要です。
* **問題2:** `user.Age = 20`
    * *解説:* `.`（ドット）でつなぐことで、構造体の中身に直接アクセスできます。変数に値を代入するのと同じ感覚で更新が可能です。
* **問題3:** `:wq`
    * *解説:* `w` は write（書き込み）、`q` は quit（終了）を意味します。ノーマルモードでコロン（`:`）を押してから入力します。もし保存せずに強制終了したい場合は `:q!` と入力します。
