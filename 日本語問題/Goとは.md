# ハッカソン特化型 Go言語ブートキャンプ

## 第1章：Go言語の世界へようこそ！〜環境構築と最初のプログラム〜

いよいよGo言語の学習がスタートします！このチャットシリーズでは、Go言語の基本から始まり、最終的にはハッカソンで簡単なWebサーバーやAPIを自力で構築し、チーム開発で活躍できるレベルを目指します。

第1章では、Go言語の特徴を知り、手元のパソコンでGoのプログラムを動かせるように環境を整え、最初のプログラムを実行してみましょう。

---

### 1.1 Go言語とは？なぜハッカソンに向いているのか？

Go言語（Golang）は、Googleによって開発されたプログラミング言語です。ハッカソンにおいて、Go言語には以下のような強力なメリットがあります。

1. **シンプルで読み書きしやすい**: 構文がシンプルに設計されているため、学習コストが低く、チームメンバーのコードも読みやすいです。
2. **実行速度が速い**: C言語やC++のように、実行前にコンピュータが直接理解できる形式（機械語）に変換（コンパイル）されるため、非常に高速に動作します。
3. **環境構築やデプロイが簡単**: 作成したプログラムは1つの実行ファイルにまとまる（シングルバイナリ）ため、サーバーへの配置（デプロイ）が驚くほど簡単です。
4. **標準機能が強力**: Webサーバーを立ち上げる機能などが標準で用意されており、外部のライブラリに頼らなくても多くのことができます。

### 1.2 環境構築をしよう

まずは、あなたのパソコンでGo言語を使えるようにしましょう。

**ステップ1：Goのインストール**
1. [Go言語の公式サイト (https://go.dev/)](https://go.dev/) にアクセスします。
2. 「Download」ボタンをクリックし、お使いのOS（Windows, macOS, Linux）に合わせたインストーラーをダウンロードします。
3. ダウンロードしたファイルを実行し、画面の指示に従ってインストールを完了させます。

**ステップ2：インストールの確認**
インストールが完了したら、ターミナル（Windowsの場合はコマンドプロンプトやPowerShell、Macの場合はターミナル）を開き、以下のコマンドを入力してEnterキーを押してください。

~~~bash
go version
~~~

`go version go1.XX.X darwin/amd64` のようなバージョン情報が表示されれば、環境構築は成功です！

### 1.3 最初のプログラム「Hello, World!」

プログラミング学習の伝統に則り、画面に文字を表示するだけのシンプルなプログラムを作ってみましょう。

1. 任意の場所に、新しくフォルダを作成します（例：`go-lesson`）。
2. お好きなテキストエディタ（VS Codeなど）でそのフォルダを開きます。
3. 新しいファイルを作成し、`main.go` という名前で保存します。
4. `main.go` に以下のコードを記述してください。

~~~go
package main

import "fmt"

func main() {
    fmt.Println("Hello, ハッカソン！")
}
~~~

**プログラムの実行**
ターミナルで `main.go` を保存したフォルダ（ディレクトリ）に移動し、以下のコマンドを実行します。

~~~bash
go run main.go
~~~

画面に `Hello, ハッカソン！` と表示されれば大成功です！あなたは今、Go言語のプログラムを見事に動かしました。

---

### 1.4 プログラムの丁寧な解説

たった数行のコードですが、Go言語の重要なルールが詰まっています。1行ずつ解読していきましょう。

* **`package main`**
  Go言語のプログラムは、必ず「パッケージ（package）」という単位で管理されます。`main` パッケージは特別で、「ここからプログラムの実行をスタートする」という意味を持ちます。実行可能なプログラムを作る際は、必ずファイルの先頭にこれを書きます。

* **`import "fmt"`**
  `import` は、外部の便利な機能（パッケージ）を「読み込む」ための命令です。ここでは `fmt` (フォーマット) という標準パッケージを読み込んでいます。`fmt` は、画面に文字を出力したり、入力文字を受け取ったりするための機能を提供します。

* **`func main() { ... }`**
  `func` は関数（function：処理のまとまり）を定義するキーワードです。`main` という名前の関数は特別で、プログラムを実行したときに**一番最初に呼び出される**部分です。中括弧 `{ }` の中に、実行したい具体的な処理を書きます。

* **`fmt.Println("Hello, ハッカソン！")`**
  先ほど読み込んだ `fmt` パッケージの中にある、`Println`（プリントライン）という機能を使っています。これは「カッコの中の文字を画面に表示し、最後に改行する」という機能です。文字列は必ずダブルクォーテーション `"` で囲むルールがあります。

### 1.5 第1章の確認問題

ここまでの内容が定着しているか、簡単な問題で確認してみましょう。頭の中で答えるだけでも構いません。

**問題1**
Go言語で、画面に文字を表示するためによく使われる標準パッケージ（`import` するもの）の名前は何ですか？

**問題2**
Goのプログラムを実行した際に、一番最初に実行される特別な関数の名前は何ですか？

**問題3**
`main.go` という名前のファイルに書かれたプログラムを実行するために、ターミナルで打ち込むべきコマンドを答えてください。

---
**【第1章の解答】**
* **問題1:** `fmt` （文字を出力したり、フォーマットを整える際に使う標準パッケージです）
* **問題2:** `main` 関数 （`func main()` はプログラムの実行スタート地点になります）
* **問題3:** `go run main.go` （コンパイルと実行を裏側で同時に行ってくれる便利なコマンドです）
